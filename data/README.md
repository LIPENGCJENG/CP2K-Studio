# CP2K 2026.1 官方数据缓存

`cp2k-2026.1/` 中的文件直接来自 [CP2K 官方仓库 v2026.1](https://github.com/cp2k/cp2k/tree/v2026.1/data)，未经修改。`manifest.json` 记录解析到的 release commit、每个文件的精确下载 URL 和 SHA-256。上游许可证见 `../schemas/CP2K-LICENSE`。

这份缓存让应用离线启动即可展示真实候选。不得因为文件名在清单中就假设其存在；运行时逐文件检查存在性、版本和指纹。用户指定目录和安装目录优先，未知版本不自动混用。用户主动声明版本的自定义文件会标记为用户数据，不能冒称官方缓存。

解析中发现的 NA、无效元素头、缺少数值或不满足严格维数检查的记录会被排除并报告。原始官方文件保持原文；不会为了填充选项而修改、补造数据。
