## 预设保存与加载

预设是独立的 `Preset` 模型，不复用项目文件作为预设。它包含格式/CP2K 版本、稳定 ID、名称、描述、分类、计算参数、可选晶胞设置、可选坐标以及草稿标记。XML 路径、原项目结构来源路径不作为默认可复用参数。

存储位置由 Qt 的 `QStandardPaths.GenericConfigLocation` 取得，再加入 `CP2K-Studio/presets`。UUID 文件名和原子写入让显示名称可安全包含中文；重命名只更改元数据，不将显示名称拼入路径。同名新预设需要选择覆盖或改名另存。草稿不标记成已通过 CP2K 语法校验，`syntax_validated` 固定为 false。

顶部内置/个人预设和管理对话框都调用主窗口唯一的 `apply_preset` 入口。核心先构建应用规划，不修改当前项目，再由 GUI 列出覆盖模块和警告。用户确认后统一加载各面板并刷新预览；取消则保留当前状态。

默认不含晶胞和坐标。两者可以分别保存，应用时必须明确确认。按 KIND 标签与真实元素匹配；当标签不同但同一元素只有唯一配置时可复用。有多个不同配置无法唯一映射或缺少目标元素时，保持该元素基组/赝势未选择并提示，避免混入其他元素的参数。

保存预设只读取当前项目副本，既不更改项目参数，也不更改现有项目文件。损坏、缺失、版本不兼容、文件 ID 不一致等会在菜单/管理界面报告，不中断其他预设的加载。

## XML 设置与校验

XML 对话框显示来源、绝对路径、规范版本及加载状态。确认前沿用 `CP2KSchema` 的 2026.1 版本检查，并确认必要 Section；没有旧规范回退。只有确认成功才更新当前项目的 `xml_spec`。

切换规范会清除当前校验服务缓存；缓存按 XML 路径及修改时间区分。顶部 XML 校验在后台使用当前项目快照，结果写入右侧报告。运行期间项目改变时，旧校验结果不会覆盖新状态。XML 切换不改变计算参数、结构或生成的 INP 内容。

## 单独 INP 导出

第七步打开保存对话框，默认 `<项目名>.inp`。程序重新收集当前有效模型，调用现有完整性校验、`generate_input` 和当前 XML 解析器，全部通过后写入。

单独导出与预览都使用生成器的内嵌 COORD 分支，因此无需外部坐标文件。基组与单来源赝势仍引用原库的实际路径，成功提示会列明依赖。多来源赝势需要的合并文件由原有 `required_artifacts` 生成在同一目录；如果同名文件已存在且内容不同，拒绝覆盖，提示改用新目录或完整计算包。

导出计算包仍调用原有 `export_bundle`，交付相对路径资源副本、结构和项目配置。项目、预设、INP 与计算包的模型和保存入口彼此明确区分。
